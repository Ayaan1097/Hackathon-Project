# Auction Alerts Feature

## Overview
The Auction Alerts feature notifies users of bank-auctioned properties available at below-market rates. This innovative solution helps users discover exclusive property deals that might otherwise be difficult to find.

## Key Features

### 1. Auction Alerts Component
- Displays featured auction properties with detailed information
- Shows discount percentage, time remaining, and property highlights
- Provides a subscription system to receive personalized alerts

### 2. Personalized Alert Preferences
- Property type selection (Apartment, House, Commercial, Land, Industrial)
- Location preferences
- Price range filtering
- Minimum discount threshold adjustment
- Multiple notification methods (Email, SMS, In-App, Weekly Digest)

### 3. Real-time Notifications
- Bell icon in the navigation bar with unread count
- Dropdown menu with latest auction property alerts
- Mark-as-read functionality
- Detail information on each notification

### 4. Comprehensive Auction Listings Page
- Advanced filtering options for auction properties
- Calendar view of upcoming auction dates
- Detailed information about auction process
- Benefits of bank auction properties
- Visual process timeline

### 5. Home Page Integration
- Featured section highlighting auction properties
- Call-to-action to explore all auction properties

## Technical Implementation

### Components Created
- `AuctionAlerts.js` - Main component for displaying auction properties and subscription preferences
- `AuctionListings.js` - Dedicated page for all auction properties with advanced filters
- `AuctionNotification.js` - Notification bell with dropdown in navbar

### Styling
- Custom CSS for auction cards with animated effects
- Responsive design for all screen sizes
- Visual countdown timers for auction end dates
- Customized form elements for alert preferences

### Data Management
- Local storage for saving user preferences
- Mock data structure for auction properties
- State management for notifications and user preferences

## How to Use

1. **View Auction Properties**: Browse featured auction properties on the home page or visit the dedicated Auction Listings page
2. **Subscribe to Alerts**: Click "Subscribe to Alerts" and set your preferences
3. **Receive Notifications**: Get notified through your preferred channels when matching properties are available
4. **Manage Alerts**: Edit or unsubscribe from alerts at any time
5. **Participate in Auctions**: View property details and follow links to participate in auctions
